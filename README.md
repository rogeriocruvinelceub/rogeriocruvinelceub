### 🛠️ Práticas de Engenharia Adotadas nos meus Repositórios
Nos meus projetos pessoais e acadêmicos, procuro sempre aplicar conceitos rigorosos da nossa área, tais como:
* **Conventional Commits:** Mensagens de histórico padronizadas (ex: `feat:`, `fix:`, `docs:`) para garantir a rastreabilidade do código.
* **Clean Code:** Legibilidade de código, separação de responsabilidades e refatoração constante.
* **Documentação Clara:** Arquivos README detalhados explicando o propósito e como executar cada aplicação.
